# RE/MAX

> RE/MAX Holdings, Inc. (NYSE: RMAX) is one of the world's largest real estate brokerage franchisors, licensing the RE/MAX brand across more than 110 countries. It is a consumer of MLS data rather than a publisher of it. RE/MAX Holdings publishes no developer portal, no API program and no machine-readable API contract in the United States. The only publicly documented RE/MAX APIs belong to RE/MAX Europe: a Datahub franchise-operations API and a Listings API, both documented as public Postman collections, both OAuth 2.0, and both credential-gated to RE/MAX regional master franchisees, offices and their vendors. Documented, but not self-serve.

This file was generated by API Evangelist from the RE/MAX provider repo. It describes what is verifiable as of 2026-07-26; the absences below are recorded findings, not omissions.

## APIs

- [RE/MAX Europe Datahub API](https://apidocs.datahub.remax.eu/): Franchise operations - offices, persons, RE/MAX Titles (role records), teams, regions and monthly GCI / transaction / volume reporting. Base URL https://api.datahub.remax.eu/external. OAuth 2.0 against https://oauth.datahub.remax.eu, token passed as an access_token query parameter. 52 documented operations.
- [RE/MAX Europe Listings API (staging)](https://listingsapi-test.datahub.remax.eu/): Property listings and listing images across RE/MAX European regions, plus listing entry logs and region/office/agent lookups. Only the STAGING environment is documented; base URL https://listing-api-remaxeu.bwscloud.tech/api/v1. Writes are queued and validated after the response. 35 documented operations.
- [RE/MAX Europe Site API (WordPress REST)](https://www.remax.eu/wp-json/): The remax.eu marketing site exposes the WordPress REST API anonymously - 42 namespaces, 791 routes, including public reads of posts, pages, media, events, regions and newsroom content. A platform default rather than a RE/MAX product, but the only anonymously callable, self-describing RE/MAX endpoint family.

## Access

- Credentials are issued by RE/MAX Europe to regional master franchisees, offices and their vendors. There is no signup form, no key request page and no published pricing. The Datahub documentation ships the client_id placeholder "Ask_REU", which is the entire onboarding process.
- The United States surface has nothing to apply for: no developer program exists. api.remax.com is a dangling CNAME to a decommissioned booj host; developer.remax.com, developers.remax.com and docs.remax.com are wildcard DNS entries pointing at the kvCORE agent-website platform.

## No OpenAPI

There is no OpenAPI, Swagger, GraphQL schema, AsyncAPI document or OData $metadata anywhere in the RE/MAX estate. Every candidate path on both API hosts, both documentation hosts and the consumer portal was probed and returned 404, a 400 auth-gate response, or an nginx/WAF block. Do not assume a generated client exists; there is none.

## RESO posture

RE/MAX is a RESO Class D member (Brokers, Agents and Appraisers) with a seat on the RESO Board of Directors, and is NOT in the RESO certification directory of certified data providers. It publishes no RESO Web API, no Data Dictionary mapping and no Universal Property Identifier. The listing schema is proprietary: listingId, offerType, noOfBedrooms, buildingSize, energyRating where RESO would use ListingKey, PropertyType, BedroomsTotal, LivingArea.
